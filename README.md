Beacon of Blessings Charity Initiative – Website

📌 Project Overview

This project is the official website for Beacon of Blessings Charity Initiative, a faith-based non-governmental organization focused on supporting vulnerable communities in Nigeria.

The website is designed as a modern, interactive digital experience rather than a traditional static NGO website. It emphasizes storytelling, engagement, and clarity of mission while remaining scalable for future growth.

⸻

🎯 Purpose of the Website
	•	Present the NGO’s mission, vision, and values
	•	Highlight programs supporting children, widows, orphans, and young girls
	•	Showcase community impact and outreach activities
	•	Enable supporters to get involved or donate securely
	•	Provide a foundation for future expansion (media, reports, campaigns)

⸻

🌍 Key Focus Areas
	•	Education support for children (school bags, books, uniforms)
	•	Food and essential support for widows
	•	Care and support for orphans
	•	Assistance and protection for vulnerable young girls

⸻

🧩 Features
	•	Modern, animation-driven user experience
	•	Storytelling-based content flow (not template-style pages)
	•	Responsive design (mobile, tablet, desktop)
	•	Secure donation integration via Stripe
	•	Contact and engagement forms
	•	Blog / updates section for outreach stories and announcements
	•	Leadership and governance information
	•	Designed for accessibility, performance, and scalability

⸻

🛠️ Tech Stack (High-Level)
	•	Frontend: Modern web technologies optimized for performance and animation
	•	Backend services:
	•	Donations: Stripe (client-owned account)
	•	Forms: Secure third-party form handling
	•	Content: Structured for easy future CMS integration
	•	Hosting: Cloud-based, production-ready environment

The architecture follows a headless approach, separating frontend experience from backend services to avoid vendor lock-in and ensure long-term flexibility.

⸻

🚀 Getting Started (For Deployment)
	1.	Configure environment variables for:
	    •	Stripe keys
    	•	Form handling service
	2.	Deploy to preferred hosting provider (e.g., Vercel, Netlify, or similar)
	3.	Connect domain and enable HTTPS
	4.	Test donation flow and forms before going live

⸻

🔐 Ownership & Control
	•	Domain, hosting, and Stripe account are owned by the client
	•	The website is built to allow future updates without redesign
	•	No proprietary lock-in to a single platform

⸻
